# Employee_Salaray_Prediction
A machine learning web application that predicts employee salaries based on job-related information.

Live Demo: [Open the application](https://employee-salaray-prediction-34ed.onrender.com/)

Tech Stack: Python, Flask, Pandas, Scikit-learn, HTML, CSS

Features: 

Interactive salary prediction interface

Machine learning-based salary estimation

Web interface built with Flask
